# PPC Master Sheet

`PPC_Master_Sheet.xlsx` is the master sheet template for every Google Ads and Meta project.
It is generated by `build_master_sheet.py` (`python ppc-master-sheet/build_master_sheet.py`).

- **Project Index**: one row per project. Type the exact tab name in column A and the other columns fill in automatically.
- **How To Use**: rules for the team and the AI agent.
- **_TEMPLATE**: duplicate this tab for each new project and rename it (e.g. `Summit Cleaning`).
- **Summit Cleaning**: the first project tab. The Drive links you shared are already filled in.

Each project tab keeps all client information in one tab, across 87 columns in 15 colour-coded sections.
Row 5 is the Master Profile, which always holds the current state. From row 6 down is the Update Log:
add one new row for every daily update, report, optimization, client message, complaint or meeting.

**Use in Google Sheets:** upload the file to Drive, then choose *Open with → Google Sheets* (or *File → Import*).
Dropdowns, formulas and colours are kept.

The AI agent skill that works with this sheet is in `.claude/skills/ppc-agency-manager/`.
