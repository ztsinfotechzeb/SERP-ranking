# PPC Master Sheet: Schema & Update Rules

Workbook: `PPC Master Sheet` (Google Sheets; the template lives in `ppc-master-sheet/PPC_Master_Sheet.xlsx`
in this repo and is generated by `ppc-master-sheet/build_master_sheet.py`).

## Tabs

| Tab | Purpose |
|---|---|
| `Project Index` | One row per project. Only column A (exact tab name) is typed; the rest are formulas pulling Row 5 of that tab + last log date. Use it for portfolio runs. |
| `How To Use` | Team rules. |
| `_TEMPLATE` | Copy this for every new project, rename to the project name. |
| `<Project Name>` | e.g. `Summit Cleaning`. **All** information about one client lives in this one tab. |
| `Lists` (hidden) | Dropdown values. |

## Project tab layout

| Row | Content | Agent behaviour |
|---|---|---|
| 1 | Banner | Ignore |
| 2 | Section group names | Ignore |
| 3 | **Column headers** | Locate columns by header text, never by letter (columns may be added later) |
| 4 | Guide / example format | Follow the format shown |
| 5 | **MASTER PROFILE** (yellow) | Current truth. Read first. Overwrite a cell when a fact changes, and ALSO log the change in a new row |
| 6+ | **UPDATE LOG** | Append-only. One row per piece of work or interaction. Never edit or delete old rows (except fixing your own typo the same day) |

### Writing a log row

1. Find the first empty row below Row 5 (column A empty).
2. Fill `Entry Date` (today), `Updated By` ("AI Agent" or team member name), `Entry Type` (dropdown value).
3. Copy `Name of the Project / Website` into the row so filtered views stay readable.
4. Write the details ONLY under the relevant columns, e.g.:
   - Daily Update → `Daily Work Update`, `Negative Keywords Added`, `New Keywords Added (from Search Terms)`
   - Weekly/Monthly Report → `Period`, `Spend`, `Impressions`, `Clicks`, `Conversions`,
     `Qualified Leads (Client Confirmed)`, `Calls / Forms / WhatsApp Split`, `Report / File Sent Link`
   - Client Communication → `Communication Channel`, `Last Client Update or Comments or Feedback (Last 3 Months)`,
     `Our Reply / Action Taken`
   - Complaint → above + `Client Complaint / Issue`, `Complaint Status`, `Risk Status`, `Risk Reason`
   - Meeting → `Communication Channel`=Meeting / Call, `Meeting Notes (MoM)`, next actions
   - Any row with follow-up work → `Next Action Plan or Recommendation`, `Action Owner`, `Due Date`, `Action Status`
5. CTR, CPL / CPA and Conv. Rate are formulas. Do not overwrite them.

### Refreshing Row 5

- On every change: budget, bidding, access, stage, tracking status, risk, next meeting, links.
- At every monthly report: rewrite `Last Optimization (Last 3 Months)` and
  `Last Client Update or Comments or Feedback (Last 3 Months)` as dated bullet summaries of the last 90 days
  of log rows, and set `Entry Date` in Row 5 to the refresh date.
- `Client Last Meeting Date` after every meeting.

### Risk Status rules

- **Green**: KPIs within 10% of target, client happy, tracking verified.
- **Amber**: KPI off target 2+ consecutive weeks, client concern raised, pacing off by more than 15%, access or tracking partial.
- **Red**: open complaint, tracking broken, lead quality dispute, payment/billing issue, churn signal, account suspended.
- Red or Amber requires `Risk Reason`, `Action Owner`, `Due Date`.

## Columns (Row 3 headers, in order)

### Entry Info

| Col | Header | What goes here |
|---|---|---|
| A | Entry Date | DD-MMM-YYYY. Profile row = last profile refresh date |
| B | Updated By (Team / AI Agent) | e.g. Rahul / AI Agent |
| C | Entry Type | Pick from list (dropdown: Master Profile, Onboarding, Access Update, Keyword Research, Ad Assets, Campaign Build, Tracking Setup, Daily Update, Optimization, Weekly Report, Weekly Conversion Report, Monthly Report, Client Communication, Client Complaint, Meeting, Competitor / Auction Review, Landing Page / CRO, Budget / Billing, Risk Update) |

### Project Details

| Col | Header | What goes here |
|---|---|---|
| D | Name of the Project / Website | e.g. Summit Cleaning - summitcleaning.com |
| E | Platform (Google / Meta) | Google / Meta / Google + Meta (dropdown: Google, Meta, Google + Meta) |
| F | Responsible Employee | Account owner name |
| G | Client Name | Client contact person + company |
| H | Account ID | Google Ads CID (xxx-xxx-xxxx) / Meta Ad Account ID |
| I | Project Stage | Pick from list (dropdown: 1-Questionnaire Sent, 2-Access Pending, 3-Keyword Research, 4-Ad Assets, 5-Campaign Build & Tracking, 6-Live & Optimizing, Paused, Churned) |
